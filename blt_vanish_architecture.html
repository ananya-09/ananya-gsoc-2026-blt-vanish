Local-first by design
All sensitive processing runs on-device. Raw URLs, passwords, and account hashes never leave the Flutter app.
Edge enrichment only
Cloudflare Workers receive only non-PII metadata: domain names, public threat indicators, opt-out templates, health pings.
Threat intel adapters
External feeds are queried through k-anonymity hashing (e.g. HIBP model) so account identifiers are never transmitted in plain form.
Security Center UI
All four modules — phishing, credentials, exposure, login anomalies — surface through one ranked triage queue with colour-coded severity and remediation CTAs.
